# 💬 ChatApp - تطبيق محادثة فوري

> تطبيق مراسلة فورية متكامل مبني باستخدام **Flutter** و **Firebase**، يدعم المحادثات النصية، إرسال الصور، الإشعارات الفورية، والعمل دون اتصال بالإنترنت.

---

## 📱 فكرة التطبيق

**ChatApp** هو تطبيق محادثة فورية (Instant Messaging) يهدف إلى توفير تجربة تواصل سلسة وآمنة بين المستخدمين. يعتمد التطبيق على **رقم الهاتف** كمعرّف رئيسي للمستخدم، مما يسهل عملية التسجيل والتواصل دون الحاجة لعناوين بريد إلكتروني معقدة.

### 🎯 الرؤية

بناء منصة تواصل عربية احترافية تركز على:
- **السرعة والأداء**: تجربة مستخدم سريعة حتى في ظل ضعف الشبكة
- **الأمان**: تشفير كامل لكلمات المرور وحماية البيانات الحساسة
- **البساطة**: واجهة مستخدم نظيفة وسهلة الاستخدام مستوحاة من أفضل تطبيقات المراسلة
- **المرونة**: دعم كامل للعمل دون اتصال (Offline Mode) ومزامنة تلقائية

## ✨ الميزات الحالية

### 💬 المحادثات
- ✅ إنشاء محادثات فردية بناءً على رقم الهاتف
- ✅ إرسال واستقبال الرسائل النصية في الوقت الفعلي
- ✅ إرسال الصور عبر ImgBB مع ضغط تلقائي
- ✅ الرد على الرسائل باقتباس (قريباً)
- ✅ علامات القراءة (مقروء / وصول)
- ✅ مؤشر الكتابة (يكتب الآن...)
- ✅ تعديل وحذف الرسائل

### 🔐 الأمان والحماية
- ✅ تشفير كلمات المرور باستخدام SHA-256 مع Salt
- ✅ إخفاء مفاتيح API في ملف بيئة (data.env)
- ✅ دعم التوافق مع كلمات المرور القديمة (Backward Compatibility)
- ✅ فحص وجودة المستخدم قبل إنشاء المحادثة

### 🌐 الشبكة والاتصال
- ✅ دعم كامل لوضع الأوفلاين (Offline Mode)
- ✅ كاش محلي (Hive) لعرض الرسائل والمحادثات فوراً
- ✅ مزامنة تلقائية مع Firebase عند عودة الاتصال
- ✅ قائمة انتظار للإشعارات المعلقة (Pending Notifications)
- ✅ مراقبة حالة الاتصال وعرضها للمستخدم

### 🔔 الإشعارات
- ✅ إشعارات فورية عبر OneSignal
- ✅ معالجة الإشعارات المعلقة عند عودة الاتصال
- ✅ دعم الإشعارات داخل التطبيق (Foreground)

### 👤 إدارة المستخدمين
- ✅ تسجيل الدخول وإنشاء حساب برقم الهاتف
- ✅ تحديث حالة المستخدم (متصل / غير متصل)
- ✅ تعديل الملف الشخصي (الاسم، البريد الإلكتروني، الصورة الشخصية)
- ✅ تغيير كلمة المرور واستعادتها
- ✅ حذف الحساب بالكامل

### 🎨 واجهة المستخدم
- ✅ تصميم عصري مستوحى من تطبيقات المراسلة الشهيرة
- ✅ أنيميشن انتقال سلس بين الشاشات
- ✅ دعم كامل للغة العربية (RTL)
- ✅ واجهة مستخدم سريعة وسهلة

## 🛠 التقنيات المستخدمة

| التقنية | الغرض |
|---------|-------|
| **Flutter** | إطار العمل الرئيسي للتطبيق (Cross-platform) |
| **Firebase Realtime Database** | قاعدة البيانات الرئيسية للتخزين والمزامنة |
| **Riverpod** | إدارة الحالة (State Management) |
| **Hive** | قاعدة بيانات محلية للتخزين المؤقت (Caching) |
| **OneSignal** | خدمة الإشعارات الفورية (Push Notifications) |
| **ImgBB API** | رفع وتخزين الصور |
| **SharedPreferences** | تخزين البيانات المحلية البسيطة |
| **flutter_dotenv** | إدارة المتغيرات البيئية والمفاتيح السرية |
| **Internet Connection Checker** | مراقبة حالة الاتصال بالإنترنت |

## 🏗 البنية البرمجية (Architecture)

```
lib/
├── Animation/          # أنيميشنات الانتقال بين الشاشات
├── Combonant/          # مكونات واجهة المستخدم القابلة لإعادة الاستخدام
├── hiveModle/          # نماذج Hive للتخزين المحلي
├── model/              # نماذج البيانات (User, Message, Chat)
├── Notifications/      # خدمات الإشعارات (OneSignal, Pending Queue)
├── Provider/           # مزودات الحالة (Riverpod Providers)
├── Screen/             # شاشات التطبيق
└── service/            # الخدمات (Image Upload, Share, Firebase)
```

## ⚙️ كيفية التشغيل

### المتطلبات
- Flutter SDK `^3.11.1`
- Dart SDK `^3.11.1`
- Firebase project مع تفعيل Realtime Database

### خطوات التشغيل

1. **استنساخ المشروع**
```bash
git clone https://github.com/adeeb2002/chat_app.git
cd chat_app
```

2. **تثبيت الحزم**
```bash
flutter pub get
```

3. **إعداد المتغيرات البيئية**
انسخ ملف `data.env.example` إلى `data.env` واملأ المفاتيح:
```env
IMGBB_API_KEY=your_imgbb_api_key
ONESIGNAL_APP_ID=your_onesignal_app_id
ONESIGNAL_REST_API_KEY=your_onesignal_rest_api_key
```

4. **إعداد Firebase**
- أنشئ مشروعاً في [Firebase Console](https://console.firebase.google.com)
- فعّل **Realtime Database**
- حمّل ملف `google-services.json` وضعه في المجلد `android/app/`
- حدّث `lib/service/firebase_options.dart` بمعلومات مشروعك

5. **تشغيل التطبيق**
```bash
flutter run
```
