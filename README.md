# ChatApp

تطبيق شات بسيط لكنه قوي، بنيته عشان أتعلم Flutter وفجأة صار مشروع كبير 😅

## الفكرة

تطبيق مراسلة يعتمد على رقم الهاتف. لا إيميلات، لا تعقيد. تدخل رقمك، تكلم الناس. ببساطة.

صراحة، بدأت المشروع عشان أفهم كيف تشتغل تطبيقات الشات من تحت الـ Hood. طلعت أعمق من ما توقعت، بس الحمدلله وصلنا لشيء شغال ونافع.

## المشاكل اللي واجهتني (عشان تكونوا مستعدين)

- **Firebase والأوفلاين**: كان فيه استعلام داخل `addPendingNotification` يعلق التطبيق لما النت يقطع. حذفته لان أساساً الـ ID يتولد محلياً وما في داعي للفحص.
- **Hive و unreadCount**: الـ Adapter كان ما يكتب الفيلد الـ 11 (unreadCount). فالمستخدم يشوف عداد القراءة صفر دايم بعد ما يسكر التطبيق.
- **SplashScreen**: كان في دالتين تنقل يتسابقوا. وحدة بعد 2.5 ثانية ووحدة بعد 3 ثواني. دمجتهم بوحدة وحدة وحليناها.
- **كلمات المرور**: لأسباب غبية، كنت احفظ كلمات المرور نص عادي في Firebase. حولتها لـ SHA-256 + Salt.

## التقنيات

- Flutter + Riverpod (للـ State Management)
- Firebase Realtime Database (ودّع SQL)
- Hive (للكاش المحلي، أسرع من SharedPreferences)
- OneSignal (للإشعارات)
- ImgBB API (لرفع الصور)
- crypto + flutter_dotenv (للأمان)

## اللي شغال دلوقتي

- محادثات نصية في الوقت الفعلي
- إرسال صور (Choose من الأستوديو أو تصوير)
- مؤشر "يكتب الآن..."
- علامات قراءة (تم الاستلام / تم القراءة)
- الأوفلاين: تقدر تفتح التطبيق وتشوف رسائلك المخزنة حتى لو النت مقطوع
- تشفير كلمات المرور
- تعديل وحذف الرسائل
- إشعارات فورية
- استعادة كلمة المرور

## اللي ناوي أضيفه (عندي وقت 😅)

1. **الرد على رسالة محددة (Reply)** - الشائع في واتساب، شدني صراحة
2. **المجموعات** - القصة أعمق شوي بس ان شاء الله
3. **وضع مظلم (Dark Mode)** - الكل يطلبه
4. **البحث داخل المحادثة**
5. **تسجيلات صوتية** - بتحتاج مكتبات معينة بس ممكن
6. **شاشة بروفايل للطرف الآخر** - حالياً ضغط على الاسم يفتح بروفايلي أنا 😂 غلطة

## كيف تشغله

```
git clone https://github.com/adeeb2002/chat_app.git
cd chat_app
flutter pub get
```

- سويلك مشروع Firebase
- فعل Realtime Database
- نزل `google-services.json` وحطه في `android/app/`
- حضر ملف `data.env` وحط فيه مفاتيح ImgBB و OneSignal

```
flutter run
```
